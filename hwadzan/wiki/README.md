# hwadzan 法教維基（LLM Wiki）

本維基以「LLM Wiki」模式維護，整理 **華藏淨宗學會（hwadzan）** 的傳統中文佛學開示。原始資料在 `doc/`（不可更動），本目錄 `wiki/` 是由 LLM 持續編寫、互相連結的知識庫。

## 三層架構

1. **原始資料** `hwadzan/doc/` — 真空分佈於各類別，約 816 個系列、近萬頁，由人擇、不可更動。
2. **維基** `wiki/` — LLM 撰寫的頁面：類別、主題、開示、概念、問答。
3. **綱要** `AGENTS.md` + `wiki/SCHEMA.md` — 規範結構與工作流程。
